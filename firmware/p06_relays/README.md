# Uno P06 릴레이 확장

기존 D2~D5 센서 스케치를 유지하고 `p06_relays.h`를 같은 스케치 폴더에 추가합니다. 현재 Jetson에서 기존 센서 스케치 소스를 찾지 못했으므로 이 확장을 보드에 업로드하지 않았습니다.

1. 릴레이 모듈의 ON 신호가 LOW인지 HIGH인지 먼저 확인합니다.
2. 기존 스케치 맨 위에 아래를 추가합니다. HIGH 동작 모듈이면 LOW를 HIGH로 바꿉니다.

```cpp
#define P06_RELAY_ON_LEVEL LOW
#include "p06_relays.h"
```

3. 기존 `setup()`의 `Serial.begin(115200)` 뒤에 `p06_begin();`을 추가합니다.
4. 기존 `loop()`에서 `p06_poll();`을 계속 호출합니다. 1초 주기 센서 출력은 유지할 수 있지만 3초 이상 블로킹하는 delay/작업은 피하세요. 다른 Serial 명령 처리기가 있으면 하나의 수신 처리기로 병합해야 합니다.
5. 컴파일·업로드한 뒤 monofactory SETTING P06의 ON 신호를 동일하게 설정합니다. 두 설정이 다르면 펌웨어는 출력 명령을 거부합니다.

사용 핀은 D8=초록, D9=빨강, D10=부저뿐입니다. 센서 D2~D5 및 예비 릴레이용 핀은 변경하지 않습니다. 부팅 시 3개 출력은 OFF이며, Jetson의 유지 신호가 3초 넘게 없으면 OFF가 됩니다. OFF 이후에는 새 출력 명령이 필요합니다.

센서 문자열은 기존 형식을 그대로 유지합니다. `P06 ACK/STATE`는 같은 115200 baud USB 연결에서 별도 종류로 해석합니다. 출력 표시는 Uno의 GPIO 논리 상태 응답이며 실제 접점이나 램프 전류를 측정한 값은 아닙니다.

릴레이 전원은 모듈 정격 5V, 경광등 부하는 접점을 통한 24V입니다. 모듈 VCC/GND/IN과 경광등 공통·색상선은 사용자 제공 배선을 기준으로 하며 실제 제품 표시를 확인하세요. 이 파일은 VCC/GND/IN이 있는 릴레이 모듈용입니다.
