# P04 USB CAN 재연결

`bash setup_can_usb.sh`는 candleLight VID:PID `1d50:606f`에 plugdev 그룹의 읽기·쓰기 권한(0660)을 적용하고 해당 장치의 USB 자동 절전을 해제한다. udev 규칙은 재부팅/재연결에도 유지된다. 실행 계정은 plugdev 그룹에 속해야 한다.

P04 REAL 연결을 시작하면 같은 CAN 전용 스레드가 유휴 상태에서 약 1초마다 센서/엔코더 응답을 확인한다. 연결 실패 시 USB 핸들을 해제하고 다시 탐색한다. 첫 정상 연결 시 어댑터 고유번호를 `p04.can.usb_serial`에 저장하며 이후 USB Bus/Device 번호 또는 포트가 달라져도 같은 고유번호의 장치를 선택한다. 고유번호가 없으면 동일 VID:PID 어댑터가 정확히 하나 있을 때만 연결한다. 어댑터 교체 시 저장된 고유번호를 비운 뒤 서버를 재시작한다.

재연결은 CAN 상태 조회만 수행한다. 이전 이동 명령은 재전송하지 않으며, ENABLE/HOME/사이클도 자동 실행하지 않는다. 연결 상실 시 이전 호밍·활성 상태를 해제한다. 복구 후 P04 ENABLE 및 HOMING은 사용자가 실행한다. SIM 전환/서버 종료 시 재연결 작업을 중단한다.

USB 장치 자체가 시스템에 나타나지 않거나 CAN 버스 전원·배선·종단이 불량하면 코드만으로 연결할 수 없다. 상태창의 오류 원인과 실제 USB 연결 상태를 확인한다.

검증: 모의 장치로 초기 미연결 후 연결, 분리 후 같은 장치 재연결, 단일 USB 소유 스레드, 종료 시 재시도 중단, 오류 로그 중복 억제 및 기존 STOP/이동 제어를 확인한다.
