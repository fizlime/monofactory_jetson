# P01 EE-SX 원점 감지 후 전진

P01 HOME은 EE-SX 원점 감지 → 해당 지점을 0 mm로 설정 → 설정한 양만큼 전진 → COMPLETE 확인 → 호밍 완료 순서다. 처음부터 센서가 감지 중이어도 전진 단계를 수행한다. 마지막 대기 위치는 원점에서 +전진 거리이며 자동 사이클의 별도 왕복 거리는 유지한다.

SETTING → P01의 축별 `호밍 후 전진 거리 (mm)`를 설정한다. `p01.axes.E0.home_forward_mm`부터 E3까지 각각 저장한다. 빈칸/null은 미정이며, 실제 이동 가능한 양수만 허용한다. 거리가 미정이면 해당 축은 호밍 대기 상태로 남는다. 이동 실패나 STOP은 호밍 완료로 처리하지 않는다.

현재 E0–E3 네 축을 사용하도록 설정했다. EE-SX 연결 보드·핀·출력 방식과 전진 거리는 아직 미정이다. 실제 EE-SX 입력 드라이버/배선 적용은 해당 정보 확정 후 진행한다. Uno D2–D5는 기존 자재 감지용으로 유지한다. 기존 탐색은 짧은 구간 이동 후 입력을 확인하는 방식이며, 실제 센서 적용 시 입력 갱신과 정지 거리를 함께 검증해야 한다.

MAIN 전체 호밍과 MANUAL P01/축별 HOME에 같은 절차가 적용된다. 실제 생산 사이클에는 HOME을 추가하지 않는다. 이번 검증은 Python 모의 장치와 브라우저 테스트이며 실제 호밍 이동을 실행하지 않았다.
